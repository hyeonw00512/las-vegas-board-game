# 라스베가스

실시간 멀티플레이 주사위 배치형 웹 보드게임입니다. PC와 모바일 브라우저가 같은 방 코드로 함께 플레이할 수 있습니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 다른 탭이나 같은 네트워크의 다른 기기에서 서버 주소로 접속한 뒤 같은 방 코드로 참가할 수 있습니다.

PowerShell에서 `npm.ps1` 실행 정책 오류가 나면 프로젝트 폴더 안에서 아래처럼 실행합니다.

```powershell
npm.cmd install
npm.cmd start
```

## 테스트

```bash
npm test
```

## GitHub와 Render 배포

1. 이 폴더를 GitHub 저장소의 `main` 브랜치에 푸시합니다.
2. GitHub Actions가 자동으로 `npm ci`와 `npm test`를 실행합니다.
3. Render 대시보드에서 **New → Blueprint**를 선택하고 GitHub 저장소를 연결합니다.
4. 루트의 `render.yaml`을 확인한 뒤 Blueprint를 적용합니다.
5. 배포가 끝나면 Render 주소의 `/health`가 `{"ok":true}`를 반환하는지 확인합니다.

Render는 `PORT` 값을 자동으로 전달하며 서버는 모든 네트워크 인터페이스에서 이를 사용합니다. 현재 방 상태는 서버 메모리에만 있으므로 무료 인스턴스가 재시작되면 진행 중인 방은 사라집니다. 또한 여러 서버 인스턴스로 수평 확장하기 전에는 공유 저장소와 Socket.IO 어댑터가 필요합니다.

## 현재 구현 범위

- Node.js + Express + Socket.IO 서버
- 방 생성 / 방 코드 참가
- 2~5인 로비, 준비 상태, 방장 시작
- 플레이어 색상 자동 배정
- 서버에서 생성하는 6개 장소 보상
- 서버 RNG 주사위 굴림
- 서버가 참가자별로 본인 주사위만 전달하는 비공개 주사위 상태
- 굴림 애니메이션 및 같은 숫자 묶음 선택
- 서버 검증 기반 턴 진행과 실제 장소 배치
- 남은 주사위가 없는 플레이어 자동 건너뛰기
- 모든 브라우저에 배치 및 다음 턴 실시간 동기화
- 플레이어 색상 주사위와 실제 3×3 눈금 배치
- 2인(각 4개), 3·4인(각 2개) 흰색 중립 주사위
- 3인전의 남는 흰색 주사위 2개 시스템 자동 배치
- 54장 지폐 덱 셔플 및 카지노 1~6 순차 배분
- 장소별 동률 플레이어 제거와 순위별 보상 지급
- 중립 주사위가 획득한 지폐 폐기
- 라운드 결과 화면과 선플레이어 순환
- 4라운드 누적 금액 최종 순위
- 방 안 실시간 채팅과 모바일 채팅 서랍
- 새로고침 및 일시적 접속 끊김 후 기존 플레이어 복구
- 참가자 연결 상태 표시와 60초 재접속 유예
- 게임 종료 후 다시 하기와 로비 복귀
- 로비 및 결과 화면에서 방 나가기
- 진행 중 게임 포기 확인, 즉시 경쟁·점수판·최종 순위 제외 및 남은 인원 계속 진행
- 브라우저 생성 효과음과 사운드 ON/OFF 저장
- `client/sounds`에 넣는 MP3 효과음·Azure 안내 음성 자동 재생(파일이 없으면 기본 효과음 유지)
- 내 차례·중립 주사위 자동 배치 효과음, 카지노 칩 낙하 애니메이션
- 마지막 주사위 배치 후 3.5초 게임판 강조, 마지막 배치 위치·참가자 표시
- 정산 화면의 최종 카지노 판, 마지막 배치 문장, 참가자별 이번 라운드 수익 요약
- 카지노별 순차 정산 등장 애니메이션
- 방 생성 시 최대 인원·개인 주사위·라운드·턴 시간 설정
- 서버 권한 턴 카운트다운과 시간 초과 자동 배치
- 참가·배치·정산·시간 초과 게임 로그
- PC / 모바일 반응형 UI, 노치 안전 영역과 동적 화면 높이 대응
- 키보드 포커스, 규칙 탭 탐색, 모션 감소 설정 지원
- 내 차례 상단 배너·게임판 강조·브라우저 탭 제목 알림
- 모바일 세로 화면 회전 안내와 가로 화면 전용 고밀도 배치
- 선택한 주사위와 같은 번호의 카지노 카드를 눌러 바로 배치
- 방 코드와 공유용 초대 링크 복사·붙여넣기 참가
- GitHub Actions 자동 테스트와 Render Blueprint 배포 설정

다음 배포 단계에서는 GitHub 저장소를 연결하고 Render Blueprint를 적용하면 됩니다.

## 실제 사운드 넣기

`client/sounds` 폴더에 아래 파일명을 그대로 사용해 MP3 파일을 넣으면, 해당 상황에서 기본 전자음 대신 실제 음원이 재생됩니다. 파일이 하나라도 없으면 그 항목만 기존 기본 효과음으로 안전하게 대체됩니다.

| 파일명 | 재생 상황 | 권장 출처 |
| --- | --- | --- |
| `dice-roll.mp3` | 주사위 굴리기 | 무료 효과음 |
| `dice-place.mp3` | 주사위 배치 | 무료 효과음 |
| `neutral-place.mp3` | 흰색 중립 주사위 자동 배치 | 무료 효과음 |
| `round-result.mp3` | 라운드 정산 | 무료 효과음 |
| `next-round.mp3` | 다음 라운드·재시작 | 무료 효과음 |
| `victory.mp3` | 최종 승리 | 무료 효과음 |
| `your-turn.mp3` | 내 차례 | Azure Speech로 만든 짧은 안내 음성 권장 |

Azure Speech로 만든 음성은 **생성 후 MP3로 내려받아** `your-turn.mp3`로 저장합니다. Azure 키·엔드포인트는 브라우저 코드나 GitHub에 넣지 않습니다. 효과음은 사용 전 각 파일의 라이선스 조건을 확인하고, 출처 표기가 필요한 경우 별도 크레딧 파일에 기록합니다. 자세한 파일 규칙과 예시 문구는 [`client/sounds/README.md`](client/sounds/README.md)를 참고하세요.
